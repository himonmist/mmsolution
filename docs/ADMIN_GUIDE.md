# CMS Admin Guide

Sign in at **/admin** (forgot password → emailed link, valid 30 minutes).

## Roles
| Role | Can do |
|---|---|
| Super Administrator | Everything, including users & roles |
| Administrator | Everything except managing users |
| Content Editor | Homepage, services, projects, testimonials, news, pages, banners, media |
| Product Manager | Products, categories, brands, media; view inquiries |
| Inquiry Manager | View, update, assign, note and export inquiries |

## Before launch — content checklist
1. **Site settings → Contact**: real phone, email, address, WhatsApp number (format `8801XXXXXXXXX` — enables the floating WhatsApp button and product WhatsApp inquiries).
2. **Social**: Facebook, LinkedIn, YouTube URLs (optionally enable the Facebook feed on the Contact page).
3. **Brands**: deactivate any brand you do not actually supply; upload official logos you are permitted to use.
4. **Products**: items marked *Sample* are illustrations — edit them with real models/specs or delete them. Untick "Published" to hide.
5. **Projects**: publish only verified, completed projects; add client names only with permission. Delete the sample projects.
6. **Testimonials**: add only genuine client feedback (the section is hidden while empty).
7. **Homepage → Statistics**: add only verified figures (years in business, projects completed…).
8. **Pages**: review Privacy Policy and Terms with your legal advisor.

## Everyday tasks
**Add a product** — Products → *Add product*: name, category (required), brand, model, descriptions, features (one per line), specifications (label/value/optional group), images (upload or pick; first image is the main image), availability, *Price display* (Request a Quote / Call for Price / Show price / Hide), Published, Featured (shows on homepage), New arrival, SEO title/description. Leave *URL slug* blank to generate it.

**Reorder** — use ↑ ↓ in any list (products, categories, brands, services…).

**Inquiries** — new inquiries show a red badge. Open one to see details, reply by email/phone/WhatsApp, change status (*New → In Review → Quotation Sent → In Progress → Completed → Closed*), assign a staff member and add internal notes. *Export CSV* respects the current filters.

**Media library** — drag & drop images (JPEG/PNG/WebP/GIF/AVIF ≤ 8 MB). Files are optimised to WebP and stripped of location metadata automatically.

**Pages** — create pages with the rich-text editor; published pages appear at `/p/<slug>`. Draft pages are hidden.

**Banners** — promotional banners per placement (homepage, products, solutions) with optional button link.

**Chatbot** — Site settings → Integrations: enable/disable and edit the greeting. It answers common questions (products, networking, CCTV, servers, quotes, contact, hours) using live catalogue data and hands off to WhatsApp.

**Activity log** — every sign-in, failed sign-in, change and export is recorded.

## Security tips
Use a unique 12+ character password · never share accounts — create one per person with the least-privileged role · deactivate leavers immediately (Users & roles) · changing a user's password signs them out everywhere.
